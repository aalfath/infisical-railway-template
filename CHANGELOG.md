# Changelog

Each entry is one version of this Railway template. Breaking changes are listed first.
Deployers get an "update available" notice in Railway when a change is merged to `main`.
Read the entry before you apply it, and back up your Postgres database first: Infisical
runs its database migrations automatically when the new version starts.
